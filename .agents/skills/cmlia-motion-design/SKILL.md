# 给状态变化一个看得懂的过程

先查真实路由、组件、数据来源与已有动画。明确 **触发 → 哪个图层动 → 最终状态 → 如何中断**。如果同一区域已有循环运动，优先复用或减少它，而不是再加一个循环。

| 需要表达 | 选择 | 避免 |
|---|---|---|
| 选项从 A 到 B | 一块共享选中背景平移；文字、焦点、命中框不动 | 两个选项同时高亮或改变标签宽度 |
| 请求尚未返回 | 按最终布局留出骨架；数据到达立即替换，出错停止 | 用固定计时模拟接口，或给空状态继续扫光 |
| 已知完成量 | 回调值驱动 `scaleX`；文本和 ARIA 直接使用最新值 | 计时器伪造百分比，或等动画播完才开放操作 |
| 显示新素材 | 从图片自身的 `load` 触发局部入场；失败保留原处理 | 每次列表更新都让所有图重新变模糊 |
| 强调操作 | 用细描边、局部聚光或轻微抬升，焦点有独立静态样式 | 移动整个点击区、整页监听鼠标或让按钮追着手指跑 |

需要匹配参考中的具体效果、时间点和反例时，读 [24 项视频索引](references/video-atlas.md)。参数是起点，不是每个组件都必须使用的规范。

**实现顺序：** 先做不动也成立的状态；再叠加 CSS transition、单次 keyframes 或可取消的 Web Animation。仅在确实需要指针位置时使用 JS。跟随效果同时限定细指针、悬停和 `prefers-reduced-motion: no-preference`。高频输入期间不通过响应式状态重绘整页；离屏或后台不继续推进循环。处理退出时的焦点和再次点击，不只做第一遍播放。

**交付时区分：** 现有复用、新增并接入、仅保留作为参考。写明在哪个真实页面、怎样触发、静态替代是什么。文件存在不等于组件被渲染，生产包构建成功也不等于生产已切换。
