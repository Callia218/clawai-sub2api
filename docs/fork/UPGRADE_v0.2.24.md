# 0.2.24-clawai.1

本次在本站 `53ce319` 上合并[上游 v0.2.23 与 v0.2.24 之间的差异](https://github.com/Wei-Shaw/sub2api/compare/v0.2.23...v0.2.24)。目标标签对应 `5c2982a81b46e2142d0143d2f83c1ce9c4da1d24`。

- 模型广场新增复制模型 ID 的按钮。保留本站的广场访问权限、请求驱动的加载状态、公开动效演示和设计 Skills。
- 网关更新了请求解析和模型映射、OAuth 账号调度、用量记录；计费预留、结算和在途费用限制继续沿用本站策略。详见[上游发布说明](https://github.com/Wei-Shaw/sub2api/releases/tag/v0.2.24)。
- 自定义客户端需要避免发送同名字段。该版本拒绝歧义请求，不应依赖旧版对重复字段的处理顺序。
- 相对于本站上一版，本次没有新增 SQL 迁移，也未变更 Go 或前端依赖锁文件。分别使用独立静态前端和后端容器的部署，应从同一版本构建两者，并保留上一版资产供已打开的页面加载。
